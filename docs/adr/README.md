# ADR（Architecture Decision Record）

人間と決めた**判断とその理由**を置く。`adr` スキルが出力する。

- 1決定 = 1ファイル。ファイル名は `NNNN-<短い英語スラッグ>.md`（`0001-` から4桁ゼロ埋めの連番）
- 書き方は [0000-template.md](0000-template.md) に揃える。番号 `0000` はテンプレート専用で、決定には使わない
- **決定を変えるときも、過去のADRは書き換えない。** 新しいADRを追加し、古い方のステータスを「置き換え済み（→ NNNN）」にする（なぜ前の判断が覆ったかが記録として残る）
- 計画書（`docs/plans/`）との違いは、**計画書が「何を作るか」、ADRが「なぜその選択にしたか」**。実装が終われば計画書は役目を終えるが、ADRは判断を見直すときまで残る
- 決めていないこと・検討中のメモは置かない（検討は計画書、作業ログは `docs/history/`）
