# 作業記録（history）

`work-log` スキルが残す日報形式の記録。ファイル名は `YYYY-MM-DD-<タスクの短い名前>.md`。

**ここはAIに読まれない前提の置き場所です。** タスクを始めるときにこのディレクトリを読む仕組みはありません（意図的にそうしています——大半の記録は次のタスクと無関係なので、毎回読むとコストだけがかかる）。

次のタスクに効かせたい知見は、ここに書いて終わりにせず、**1行に削って `CLAUDE.md` か該当スキルへ移してください**。移し先は必ず読まれるので、そこに1行ある知見と、ここに1,000文字ある知見とでは、届く確率が違います。

- 中身は「やったこと / 詰まった点・解決方法 / 次回への申し送り」
- 昇格させずここに残るものは、**人間が後から経緯を追うための記録**。それ自体に価値はあるが、AIの挙動は変わらない
- 仕様の正本にはしない（仕様は `CLAUDE.md` と設計ドキュメント）
